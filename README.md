Summary :
"Enhance your travel experience! Explore 7-day weather forecasts for major European cities. Plan your trip effortlessly. Book now!"


Solution :
Users select a city from the dropdown menu.
Clicking the "Get Forecast" button triggers a request to the OpenWeatherMap API for the selected city.
The fetched weather data is processed and displayed on the webpage, showing a 7-day forecast.
The user can easily navigate and explore weather details for different European cities.


Approach:
The project involves developing a user-friendly webpage for a European travel agency. Visitors can access a 7-day weather forecast for major cities, enhancing their trip planning experience. The HTML structure includes a city dropdown and a button to trigger forecast retrieval. JavaScript fetches data from the OpenWeatherMap API, dynamically updating the webpage. Stylish CSS ensures an appealing design.
